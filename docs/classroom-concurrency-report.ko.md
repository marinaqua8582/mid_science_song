## 자동 시험 결과

25명의 합성 학생을 사용했다. API와 브라우저 각각 첫 화면·로그인·단계별 저장·최종 제출을 병렬 실행했다. API 시험은 모두 같은 `x-forwarded-for` IP를 사용했다. 브라우저도 같은 로컬 네트워크 IP이며 각 학생의 쿠키와 localStorage는 격리했다.

**모든 시나리오 성공률 100%. 중복 행 0, 누락 행 0, 다른 학생 덮어쓰기 0.**

이 값은 **로컬 기능 시험 수치**다. Google/Vercel 실서비스 응답시간이 아니다. 실제 `Code.gs`를 동기 VM으로 실행하고 Apps Script 전송은 고정 2ms로 모형화했다. JS 실행과 쓰기는 직렬화하고 잠금 실패는 주입했다. 따라서 실제 Apps Script 실행 슬롯·할당량·Sheets RPC 지연·실제 잠금 대기 성능을 증명하지 않는다. Gemini도 합성 응답만 사용했고 실제 키나 유료 API를 사용하지 않았다.

100회의 단계 저장+25회 과거 요청 재전송 구간에서 명단 읽기는 공개/비공개 각각 1회, 전체 탭 목록 탐색 1회, 반복 전체 제출 행 탐색 0회였다. 행 수와 각 학생의 학습 내용·생성/수정 가사·최종 상태를 검증했다.

추가 통과: 응답 유실 후 같은 ID 재시도, 더 최신 저장 이후 과거 요청 재전송, 같은 ID의 다른 내용 거부, 100개 기록에서 제거된 ID 재적용 거부, 잠금 시간 초과 503, 캐시 제거·행 순서 변경 복구, Legacy 저장, 비로그인 저장 거부, 학생별 반복 로그인 제한, 명단 수정/삭제/교체/편집 트리거 캐시 무효화, Gemini Retry-After 전달, 일반 400/401/403/409/429/500 저장 오류 무재시도, 지수 백오프·3회 상한, 기존 추가 열 보호.

브라우저에서는 Gemini 버튼을 같은 이벤트 루프에서 두 번 눌러 25명당 실제 공급자 모형 호출이 정확히 25회인지 검증했다. 저장 확인을 의도적으로 보류한 동안 버튼 disabled와 단계 유지, 이후 400 실패 때 다음 단계로 이동하지 않는 것도 검증했다.

## 남은 확인과 제한

1. 별도 빈 Sheets/GAS와 Preview에서 실제 25명 시험이 필요하다. 운영 자료를 복사하지 않는다. 실제 Apps Script 지연·일일 서비스 할당량·동시 실행 슬롯과 Vercel 플랜의 함수 제한은 로컬 시험 대상 밖이다.
2. 실제 Gemini 프로젝트의 RPM·TPM·일일 제한, 요금 티어 및 기존 `gemini-3.6-flash` 모델 사용 가능 여부를 AI Studio에서 확인해야 한다. 학생별 10회/30분은 프로젝트 RPM과 다르다. [Google 공식 제한 문서](https://ai.google.dev/gemini-api/docs/rate-limits).
3. Gemini 429/503 백오프는 일시 오류를 완화하지만 지속적인 용량 부족을 해결하지 않는다. 재시도는 기존 학생별 생성 한도에도 포함된다. 장시간 Retry-After는 자동 반복 대신 오류를 표시한다.
4. IP 제한은 기존 서버 인메모리 방식을 유지하므로 인스턴스 재시작/분산 상황에서 엄격한 전역 IP 제한이 되지는 않는다. 같은 학생 반복 시도는 GAS ScriptProperties+ScriptLock으로 서버 인스턴스 간에도 공유 제한한다.
5. 앱 밖에서 직접 쓰거나 정렬하면 트리거 설정과 캐시 갱신을 확인해야 한다. 같은 학생이 여러 장치에서 서로 다른 requestId로 오래된 전체 내용을 저장하는 충돌에는 별도 버전 기반 동시 편집 정책이 없다. 이번 시험은 서로 다른 25명과 동일 ID 재전송을 검증했다.
6. 이미 있던 중복 행은 자동 정리하지 않았다. 최신 100개 ID 밖의 재전송은 성공 재응답 대신 안전하게 거부한다. watermark는 ID의 클라이언트 생성 시각을 사용하므로, 100회 이상 저장 후 크게 과거로 틀어진 학생 기기 시계는 정상화가 필요할 수 있다.
7. `_requestJournal`에 사용할 U열/Legacy S열에 기존 추가 자료가 있으면 저장을 거부한다. 배포 전 별도 검토 없이 해당 열을 덮어쓰지 않는다.
8. 운영 최종 확인이 필요하다면 지정된 2학년 5반 25번 김과학, 26번 이삼진만 사용한다. 이번 작업에서는 이 계정도 열지 않았다.

Apps Script 새 배포 대상, 트리거 설치, 기존 버전을 유지하는 전환 및 롤백 순서는 `classroom-concurrency-deployment.ko.md`에 구분했다.
